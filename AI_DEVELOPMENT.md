# AI development disclosure

This standalone app was developed with AI assistance.

## What that means

- The project owner supplied the original idea, functional requirements, testing feedback, feature choices and release decisions.
- AI assistants generated and revised most of the source code, automated tests, build configuration and documentation through an iterative conversation with the project owner.
- The project owner manually exercised the functionality in Elite Dangerous, identified failures and requested corrections and additional features.
- Automated tests were created during development, but they do not prove that the application is free of defects.

The intention of this disclosure is to describe the development process plainly, not to imply that AI-generated code is inherently correct or that the project received an independent security audit. Users and contributors are encouraged to inspect the source, report problems and submit improvements.

This is an unofficial community project. It is not affiliated with or endorsed by Frontier Developments, Elite Dangerous or EDCoPilot.
